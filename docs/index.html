🧠 The 4D State Representation & Mathematical Formulation

1. Solving the "Acceptance Rate Trap"

In the original paper, state was modeled as a 1D scalar \(S = [\text{acceptance\_rate}]\). On authentic data, this caused severe state aliasing: during population drift (-20 FICO), approval volume drops. The naive 1D agent misinterprets this as "policy is too strict" and mistakenly loosens cutoffs into toxic credit right when macro defaults are escalating.

2. Active-Range 4D State Space

We expanded the observation space with active-range scaling into \([0.0, 1.0]^4\):

$$\mathbf{S}_t = \begin{bmatrix} \text{norm\_acc\_rate}_{t-1} \\[6pt] \dfrac{\text{batch\_mean\_fico}_t - 650}{150} \\[6pt] 1 - \text{norm\_acc\_rate}_{t-1} \\[6pt] \dfrac{\text{smooth\_prev\_default\_rate}_{t-1}}{0.25} \end{bmatrix} \in [0.0, 1.0]^4$$

3. Model Architecture

  • Feature Projection: 2,000-dimensional Gaussian Radial Basis Function (RBF) kernel via RBFSampler(gamma=2.0).
  • Action Space: 34 discrete cutoff actions mapping FICO 660..820 (in steps of 5) plus emergency STOP_LENDING freeze action.
  • Dense Counterfactual Batch Updating: Vectorized off-policy calculation across all 34 candidate thresholds simultaneously per cohort, eliminating action blind spots and enabling instant adaptation without conservative policy lock-in.
  • Experience Replay & Mini-Batches: Online experience replay (\(\alpha = 0.014\), mini-batch size 32, \(\gamma = 0.95\)) calibrated for bi-weekly life-of-loan horizon.
